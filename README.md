# Caddy License Authentication Middleware
This repository contains a Caddy v2 module, providing a middleware that authenticates users by license key. This is used to authenticate users for the Pextra Debian repository.

## Development
The [Caddy module development instructions](https://caddyserver.com/docs/extending-caddy) apply. Assuming `xcaddy` is installed, you can run the following command to build a temporary Caddy binary with this module included:
```bash
xcaddy run
```

An example [Caddyfile](./Caddyfile) is provided.
